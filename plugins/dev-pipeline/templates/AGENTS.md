요약:

- 기술 스택·빌드·테스트 명령은 CLAUDE.md 의 "기술 스택", "빌드·테스트 명령" 섹션에 있다.
- 계약 문서는 `docs/` 에 있고, 사람 승인 없이 바꾸지 않는다.
- 작업 하나 = worktree 하나. 할당받은 파일 범위만 수정한다.
- 완료 조건: 빌드 성공 + 테스트 통과 + 리뷰 블로커 0.
