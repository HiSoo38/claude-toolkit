## 계약 문서 (docs/)

기능 구현은 아래 세 문서가 확정된 뒤에 시작한다. 순서는 requirements → schema → api-spec.

| 문서 | 경로 | 작성 에이전트 |
| --- | --- | --- |
| 요구사항 | `docs/requirements.md` | planner |
| 스키마 | <!-- TODO: docs/schema.sql 또는 docs/schema.md --> | db-designer |
| API 명세 | `docs/api-spec.md` | api-designer |

규칙:

1. 구현 중 계약과 맞지 않는 부분을 발견하면 코드를 계약에 억지로 맞추거나 계약을 고치지 말고, 멈추고 보고한다.
2. 계약 변경은 사람이 승인한 뒤 해당 문서 담당 에이전트가 고친다.
3. 각 문서의 "미정 사항" 이 비어야 확정으로 본다.
